# slime_mould_optimization_algorithm

An interactive simulation inspired by the behavior of Physarum polycephalum (slime mould) to demonstrate network exploration, route formation, path retraction, and transportation network optimization.

## Features

- Slime mould exploration
- Mucus trail formation
- Multiple route formation
- Route retraction
- Progressive subway network formation
- Train movement across the network
- Interactive route planning
- Optimal route visualization

## Technologies Used

- HTML
- CSS
- JavaScript
- Canvas API

## How to Run

Open `physarum-tokyo-subway.html` in a web browser.
